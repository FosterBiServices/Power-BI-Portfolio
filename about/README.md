# About Foster BI Services

<img src="../assets/brand/foster-bi-icon.svg" alt="" width="64" align="right">

**Foster BI Services** is a Power BI consultancy founded by **Steven Foster**. We build Power BI reports and semantic models that people trust, and fix the ones that have grown slow or hard to maintain.

Steven is a Power BI developer who often works where Copilot is the only AI tool allowed. That constraint led to the free [SF Power BI Toolkit](https://fosterbiservices.github.io/Power-BI-Toolkit/): browser-based tools for designing reports, shaping data, building and checking semantic models, and documenting them, with nothing to install and nothing uploaded. Client work gets the same habits: clear models, measures tested against figures you trust, and documentation your team can pick up after handover.
