# Python Toolkit

Collection of reusable Python scripts supporting Data & Insights initiatives.

## Domains

| Domain | Description |
|----------|------------|
| Balanced Scorecard | Balanced Scorecard reporting and processing |
| DOJ AJCC Collaboration | DOJ AJCC project support |
| Financials | Financial reporting and automation |
| Shared | Reusable utilities used across domains |

## Standards

- Follow PEP 8
- Include error handling
- Include logging
- Document required inputs and outputs
- Avoid hardcoded paths
- Store configuration outside source code
