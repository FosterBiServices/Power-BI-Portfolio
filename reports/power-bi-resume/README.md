# Power BI Résumé

My résumé built as an interactive Power BI report: career timeline, roles, skills by category, projects, achievements and certifications. Selecting a role filters the skills and accomplishments tied to it.

**File:** [`Power BI Resume Steven Foster.pbix`](./Power%20BI%20Resume%20Steven%20Foster.pbix)
