# Power BI Résumé

The résumé of Steven Foster, founder of Foster BI Services, built as an interactive Power BI report: career timeline, roles, skills by category, projects, achievements and certifications. Selecting a role filters the skills and accomplishments tied to it.

**File:** [`Power BI Resume Steven Foster.pbix`](./Power%20BI%20Resume%20Steven%20Foster.pbix)

## Model at a glance

| | |
|---|---|
| Tables | 12 (work experience, descriptions, skills, job-skill bridge, projects, achievements, certifications, assets, date) |
| Measures | 28 |
| Relationships | 7 |
